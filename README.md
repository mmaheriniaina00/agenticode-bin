# agenticode — binary releases

Prebuilt Linux x86_64 archives of agenticode, a native editor built around coding agents (Claude Code).
Download one from [Releases](../../releases); each release lists install steps.

Arch Linux: `agenticode-bin` on the AUR.

Source code is not published here. Binaries are licensed under GPL-3.0-or-later (see `LICENSE`).
